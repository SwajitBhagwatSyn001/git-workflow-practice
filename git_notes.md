# Git Workflow Practice

## Objective
Practice basic Git commands and understand how teams collaborate using branches and pull requests.

## Commands Practiced
- `git clone` — Copy a remote repository.
- `git branch` — View branches.
- `git switch -c` — Create and switch to a branch.
- `git add` — Stage changes.
- `git commit` — Save changes locally.
- `git push` — Upload commits to GitHub.
- `git pull` — Download and integrate remote changes.
- `git merge` — Combine branch changes.
- `git rebase` — Replay commits on another base branch.

## Pull Request Workflow
1. Create a feature branch.
2. Make changes and commit them.
3. Push the feature branch to GitHub.
4. Open a pull request against `main`.
5. Review and merge the pull request.

## Learning Outcome
Learned how Git tracks changes and how branches and pull requests support collaboration.
